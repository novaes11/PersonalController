# ai-agents-core-test

Repositório para testes e experimentos utilizando a biblioteca/framework **ai-agents-core**.

## Descrição

Este repositório foi criado para servir de ambiente de teste e desenvolvimento de protótipos com o `ai-agents-core`.

## Como usar

1. Clone o repositório:
   ```bash
   git clone git@github.com:novaes11/ai-agents-core-test.git
   ```
2. Adicione seus scripts e testes neste repositório.
